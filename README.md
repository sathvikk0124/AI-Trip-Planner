🚉 AI Trip Planner ✈️

An AI-powered travel itinerary generator built with Streamlit and Google Gemini.

🔑 Setup Instructions

This app requires a Google Gemini API key.

Step 1: Get API Key

Go to: https://aistudio.google.com

Generate a free API key

Step 2: Add Key to Streamlit

In Streamlit Cloud:

Go to App Settings → Secrets

Add:

GOOGLE_API_KEY = "your_api_key_here"

Click Save

Reboot the app

Now the AI itinerary generator will work.
